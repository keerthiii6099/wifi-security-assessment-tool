# WiFi Security Assessment Tool

A Python-based WiFi Security Assessment Tool developed to evaluate wireless network security using a Streamlit dashboard.

## Project Overview

This project provides a dashboard for assessing WiFi network security. It uses simulated wireless network data to demonstrate encryption assessment, visualisation and security recommendations.

## Key Features

- Simulated WiFi network data generation
- Wireless encryption assessment
- Identification of encryption types such as Open, WEP, WPA, WPA2 and WPA3
- Interactive dashboard using Streamlit
- Data visualisation using Plotly
- Security recommendations

## Technologies Used

- Python
- Streamlit
- Pandas
- Plotly

## Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/keerthiii6099/wifi-security-assessment-tool.git
```

2. Navigate to the project directory:

```bash
cd wifi-security-assessment-tool
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
streamlit run app.py
```

## Project Purpose

The project was developed as an academic team project to demonstrate wireless network security assessment concepts and present security-related insights through an interactive dashboard.

## Disclaimer

This project is intended for educational and demonstration purposes. It uses simulated network data and does not claim to perform a complete real-world penetration test.
